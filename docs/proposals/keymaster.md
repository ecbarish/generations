## The short version

**Keymaster** (working title; alternatives: Portfolio, Closing Day, Equity): buy, renovate,
lease, and manage a growing property portfolio. Every session is five minutes of real
decisions — scout a listing, run the numbers, make an offer, pick a renovation, approve a
tenant, time a sale. Nothing plays itself; conveniences are earned the honest way (hire a
property manager = the "hired hand" rule in docs/GOALS.md, only after you've done the job
yourself).

1. **The core loop** (one loop, about five minutes): a new listing appears → you run the
   **deal analyzer** (see below) → make an offer or pass → close → choose: renovate, lease
   as-is, or flip → collect rent over days → reinvest. Market events (rate shifts, a tenant
   issue, a hot neighborhood) keep every week different.
2. **The deal analyzer is the game.** A simple in-game worksheet — purchase price, rehab
   cost, rent estimate, cash flow — that mirrors the actual analysis Evan does in Excel.
   Getting good at reading deals *is* getting good at the game. No other arcade game teaches
   a real skill; this one does.
3. **Progression:** one duplex → a few doors on one street → mixed portfolio (residential,
   then a small commercial unit) → development deals (buy land, build, sell). Each tier
   unlocks one new decision type, never just bigger numbers.
4. **Downtime-at-work shaped:** pause-friendly, one decision a minute, runs in a tab. This
   is the game Evan originally wanted for his own breaks — short, complete, satisfying
   sessions, no ads, no energy timers, nothing that feels missing.
5. **Monetization honesty:** the full game is fun with zero payment. If monetization ever
   comes, it is cosmetics or expansions — never timers, never pay-to-win, never a feature
   held hostage. (Evan, 2026-10-12: open to honest monetization if it can genuinely earn.)

## Why this one

- **Evan's heart (scorecard x2):** highest possible. It's his profession, his degree, and the
  game he wanted for himself.
- **Fun now (x2):** high. Every minute has a decision with a visible consequence; the deal
  analyzer gives the "one more listing" pull.
- **No one else can make it:** the arcade's only game with a genuine expert behind it. That
  is also portfolio material — it demonstrates domain expertise, not just code.
- **Fits "Play, not watch":** the genre's failure mode is spreadsheets that play themselves.
  The hired-hand rule and the analyzer keep every meaningful choice in the player's hands.

Rough scorecard total: 18–19/21 (pending Evan's own scoring).

## Smallest test (the Little Ranch rule)

Before any big build: **one listing, one analyzer, one buy** — a single-screen prototype
where you run the numbers on one duplex and decide to buy or pass. One PR. If running the
numbers isn't fun, the game is wrong; if it is, the portfolio builds itself from there.
