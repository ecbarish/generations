# Realmbound newcomer feedback (RB-N1)

[PR #253](https://github.com/ecbarish/generations/pull/253), baseline main 85f5e34. No game-version bump, shared engine changes or Godot edits.

Manual loot panels no longer expire while reading or deciding who should receive an item. Uncollected field money/items live in an optional per-hero fieldLoot record, defaulting to null for older saves. A full Satchel keeps items available; collected money becomes zero in the remaining record, preventing duplicate payments. Unsuccessful retries grant no manual-loot credit. The record returns after reload or a trip to the Smithy. It blocks a new field spawn from overwriting the previous drop. Earned field AutoLoot still works when there is room and waits with its remaining drops when there is not. Dungeon individual Take and Loot all retain items that do not fit; explicit companion gifts still work.

Low-resource failures already set a short error line in the old build. Actual presses now also create a visible in-game notice; quiet readiness checks do not. Shared dialogue already handled native clicks and taps, but the phone arrival-controls row overlaid its Continue button and intercepted real taps. The measured row height now reserves scene space. Its first press also silently completed the typewriter. Realmbound now labels that action Show line, renders the reveal immediately, and changes to Continue. Click, tap, keyboard and arrival buttons share the same progression; choices remain deliberate. The typewriter and shared engine stay intact.

20 new scenarios (8997 total) cover expiry, spawn protection, partial collection, no duplicate coins/loot credit, saved field drops, the Smithy trip, older/malformed optional fields, quiet resource checks, visible low-energy input, reveal/advance labels, choice safety, and dungeon expiry/full-Satchel/gifting. browser-checks.cjs adds four-size real pointer/tap, keyboard and actual reload checks at 375×812, 1366×768, 1920×1080 and 3440×1440. It stages edge cases with the real model; it is not a human newcomer fun score or physical-phone/Safari validation. Baseline captures route exact old game-script bytes from git 85f5e34. All saves are isolated test contexts.

Reproduce from the repo root: serve.ps1, then node docs/playtests/realmbound-rb-n1/browser-checks.cjs with Playwright/local Chrome; ARCADE_TEST_ORIGIN can select another localhost port. result.json records the final count. Run node tools/run-all-checks.cjs for the full regression suites.

Limits: saved recovery covers field drops. Dungeon combat/runtime reload behavior remains its existing system; this patch keeps the live dungeon loot decision from timing out and fixes full-Satchel Take, but does not redesign dungeon saves. Overlapping Thornvale quests are the subsequent RB1.12 task.

Results: all 20 suites pass, including both Godot suites and 22 unchanged save names. Realmbound/runner-safety were repeated after the phone spacing fix and pass (8997 + 35 checks). The four-size browser run passes 48 checks without forced clicks; its first pre-fix run correctly failed when arrivalControls intercepted the tap. Local results do not claim GitHub CI or publication.
