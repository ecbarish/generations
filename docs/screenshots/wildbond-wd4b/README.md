# WD4b Saltmarsh screens

Godot 4.7.2 rendered these from the trial, with the opening skipped and the coast colour restored. Nothing here is a web export.

- [Saltmarsh Road](road.png): the coast road between Thornwood gate and the settlement. Tobin stands by the sign.
- [Saltmarsh Coast](settlement.png): the original settlement, so an old save still lands on this map.
- [Moon Pool](pool.png): the return spot a Tide partner can open. Foamglint is easier to find here.

The capture script is `wildbond-godot/tests/wd4b_screens.gd`.
