The promise and the payoff

Movement demonstrates proposed size and contact with the ground. Creatures use a single static reference pose; mirroring is a review convenience, not a directional sprite or walking animation. The simple human is a 24-pixel scale gauge, not an approved character model.

These cutouts preserve the main connected alpha region from each sheet at a 128 threshold; translucent halos and disconnected pixels are excluded from the review cutout. Original PNGs remain untouched outside Git. No species, evolution, ability, game file or save is changed.
