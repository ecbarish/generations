# Thornwood atmosphere slice

WB-THORNWOOD-LIGHT, Codex / Evan, 2026-10-17. Explicit priority: reproduce the appeal of Pokemon Battle Advanced's sprite-in-3D environment in a small native Thornwood scene. Stacks on #549. This task owns only the new export-excluded `wildbond-godot/tests/thornwood_environment/` scene/assets/checks, this report, and necessary third-party credit entries. Existing adventure maps, quests, saves, original creature designs and public exports remain unchanged.

Build one walkable forest clearing using a selected subset of Kenney Nature Kit 1.0 (CC0), real 3D trees/rocks/foliage, deliberate paths and water, warm/cool light, shadows and depth. Reuse the private prototype's movement, sprites, bag and encounter/return loop. Keep an original-creature fallback so the scene can be reviewed without private Pokemon art. No sprite generation or battle-system rewrite.

Validation will cover navigation/collision and existing encounter return, environment controls, asset provenance, native screenshots and the repository checks through the quiet launcher. PBA is a visual reference, not claimed source code. The first slice must be runnable and reviewable; production integration and exact visual parity are separate work.
