# Pokémon core and safe pilot upgrade

WB-POKE-RULES · Codex / Evan · 2026-10-17 · [PR #554](https://github.com/ecbarish/generations/pull/554), stacked on #553.

## What changed

The persistent chapter now gives Pidgey, Vulpix and Wooper their own numerical data rather than renamed Wildbond combat proxies. A local, pinned PokéAPI subset provides their base stats, dual types, capture rates, experience growth thresholds and Platinum learn levels. The supported moves are Tackle, Sand Attack, Gust, Quick Attack, Ember, Tail Whip, Water Gun, Mud Shot, Slam and Flamethrower. Each species learns at most four supported moves, automatically at its recorded level; other moves are intentionally skipped pending a proper learn/forget interface.

Battles combine both defending types (including immunity and quadruple weaknesses), STAB for either attacking type, separate physical/special stats, accuracy, PP and Quick Attack priority. Tail Whip lowers Defense, Sand Attack lowers accuracy, Mud Shot lowers Speed, and fire moves can burn. Burns reduce physical damage, deal end-of-turn damage, survive saving and are cured by the Center or defeat recovery. Temporary stages reset on switching and on each new battle. Exhausted moves offer Struggle, with recoil. Existing views, turn-event/input contracts, catch math, bag behavior and crash-safe writer are reused; the new chapter subclass leaves the earlier studies and production rules untouched.

New partners begin at Level 5. Encounters use the lead's level minus one, bounded to 3–15 for this introductory trail. A victory grants the active surviving partner `floor(defeated.base_experience * defeated.level / 7)` XP on Return to Trail, once. Growth updates stats, retains the HP deficit and spent PP, and announces newly supported moves and levels. Fainted partners stay fainted when growth is applied. Levels stop at 100. Party rows show level; partner details show type and XP remaining. Captures do not award XP.

## Existing saves

Schema 2 continues using the original chapter filename so the player need not move anything. Schema 1 is validated against **frozen #553 records**, independent of future Wildbond balance changes. Migration retains IDs, party/storage order, wallet/items, goals, counters and position. Old partners retain the pilot's implicit Level 12 and start at that level's XP threshold. Remaining HP is converted by fraction (zero stays zero). Because proxy moves do not map one-to-one, every new move receives the lowest remaining PP fraction of the old loadout, rounded down; this conservative policy avoids a free refill. The Center restores normal PP.

A separately validated `.pre-v2` backup preserves the original verified schema-one data before writing the upgraded checkpoint. It does not rotate with ordinary saves. Existing invalid migration backups hold writes instead of being replaced. Corrupt primary recovery can migrate a valid old backup. Oversized/unreadable data or a future schema in primary/tmp/bak holds writes. Old and new chapter processes must not run simultaneously. The original adventure's `journey.json` is never opened. Mid-battle closure still resumes the pre-battle checkpoint, including an unreturned result screen.

## Sources and limits

[PokéAPI documentation](https://pokeapi.co/docs/v2) describes the level-up/version, historical move and historical type fields. Inputs are pinned to `PokeAPI/api-data` revision `3eef329da031136b2206bedb6216c65bd9e095d8`; [source-manifest.json](../../../wildbond-godot/tests/journey/source-manifest.json) records 35 input URLs and SHA-256 hashes. The normalization verifier recreates the committed catalogue from verified cached inputs; `--fetch` downloads missing inputs once. No runtime network access, descriptions, battle-engine code or artwork is imported. The PokéAPI BSD notice is retained, with a credits entry. Existing imported Pokémon/trainer artwork remains external and excluded from Git/public exports.

This is a **bounded Gen IV-style rules subset**, not cartridge parity. Historical move values, Platinum learn levels and the pre-Fairy 17-type chart are selected, but defeated-species base XP uses the current pinned API values (50/60/42), not a verified Gen IV base-XP table. Stats use neutral nature, fixed IV 15 and zero EVs. Critical hits, abilities, held items, other statuses, full move effects/learnsets, evolution, trainer AI, weather mechanics and cartridge-exact rounding/order are not implemented. Ranch Berries still restore half maximum HP and escape is guaranteed. The three installed samples are not the final starter selection. No production map, original story, regional connections, save format outside this chapter or public export is changed.
