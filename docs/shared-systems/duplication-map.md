# Duplication map: Keymaster, Saltmarsh Shipping Office, Night Market, Little Ranch

Read-only survey of systems that are written more than once across four browser games. No game code moves in this note. A row marked **needs Evan** would change a save format or replace a file a player already has, and this note does not propose doing that now.

Surveyed on 10 November 2026 from `main` at `6a2d5ce7`. Open pulls that own game files, and that a later move would have to wait for, are #649 (Keymaster), #648 (Saltmarsh polish), #625 (Night Market nights) and #647 (Night Market hall entry, launcher and `index.html`). None of them own `docs/shared-systems/`.

## What is already shared

`shared/engine.js` is `window.Arcade`:

- Short scale `fmt`, `fmtI` and `fmtTime` (`shared/engine.js:11-37`), suffixes `K` through `Dc` (`shared/engine.js:11`).
- `load`, `save`, `erase`, portable `encode` / `decode`, backup list, and the "Your save" box `saveToolsHTML` (`shared/engine.js:117-166`, exported at `shared/engine.js:221-227`).
- Optional `versions`, `validators`, `migrates` and `held`. A newer `v` is refused and saving stays off; the stored text is left as it is (`shared/engine.js:44-51`, `shared/engine.js:102-116`).

`shared/idle-core.js` is `window.Idle`:

- `create` ticks every 250 ms from `Date.now()`, holds one jump to `maxOfflineSec`, and pays a closed game in `start(lastSeen)` at `offlineRate` (never above 1) when the gap is at least 60 seconds (`shared/idle-core.js:1-33`, `shared/idle-core.js:210-243`).
- `bulkCost`, `maxAffordable` and `milestoneMult` (×2 at 25, 50 and 100 unless the caller passes other steps). Default growth is 1.07 (`shared/idle-core.js:37-38`, `shared/idle-core.js:76-127`).
- The core never reads or writes storage. The game's `save` callback is what calls `Arcade.save`.

Also already shared, and used by only some of these four: `shared/settings.js` (text size and motion, `arcade-settings-v1`), `shared/sound.js` (`ArcadeSound`), `shared/feedback.js`, `shared/roster.js` (timed jobs). `tools/run-all-checks.cjs` already runs the Keymaster, idle-core, Night Market, Saltmarsh and Little Ranch pages (`tools/run-all-checks.cjs:15`). `tools/night-market-district-sim.cjs:140` calls `Idle.bulkCost` rather than a private ladder.

## 2. Ranking by payoff divided by risk

Payoff is how many copied lines a shared function would retire, and how easily those copies can drift on screen. Risk is how easily the move could change a price, a payout, a picture or a stored file. The order is payoff divided by risk. The first rows are small, already-identical helpers. Larger refactors sit lower because a mistake there changes play.

1. **Payback label.** Two identical four-line functions. Display only. Existing Night Market and Saltmarsh checks already cover the sentences.
2. **Whole-coin formatting.** Saltmarsh's `coins` and the private suffix ladder in `Idle` repeat `Arcade.fmt`. One new function, callers moved one game at a time. Keymaster's exact dollars stay put, so the risk stays off the worksheet.
3. **Welcome-back panel shell.** The title, the lead and the dismiss button match. The sentences stay in each game. Drawing with `textContent` also retires Night Market's `innerHTML` build.
4. **Bulk mode switch.** The 1 / 10 / max (and Night Market's Next) parser and the pressed-button loop match. Price caps stay in each `quote`, so the move does not retune a stall or a boat. The stored `bulk` values stay as they are.
5. **Milestone look index and "times as much".** `lookIndex` matches character for character. `timesWord` matches through ×8. Words only.
6. **Save-tools drawer.** Two identical `saveToolsHTML` mounts. Tiny payoff, tiny risk, so it ranks under the words above.
7. **Night Market's second affordability search.** `maxFit` repeats `Idle.maxAffordable` while `priceOrigin` returns 0. Payoff is real, and the risk is a wrong count of stalls, which spends the wrong coins. Worth doing only after the display helpers, and only with the current quote tests green.
8. **Saltmarsh's second 250 ms timer.** Folding captain collection into an `Idle` tick hook removes a parallel clock. The risk is a missed or double haul. `Roster` already owns the job clock, so the payoff is smaller than it looks.
9. **Save boot helper.** The register / load / held-guard lines match, and the damaged-file policy does not. Unifying that policy can replace a stored file. **needs Evan.** Not proposed now.
10. **Web Audio context.** The oscillator envelope is similar, and the games are not. Little Ranch's preference key and Saltmarsh's `sound` field **need Evan** before either record changes. Not proposed now.
11. **Pictures, settings gear, Keymaster's mortgage, Little Ranch's frame loop.** These are separate games that happen to draw rectangles or open a card. Sharing them would add a module and remove no real copy.

## 3. Migration paths for the top five

Each path adds the shared function first, points one game at it, then the other, then deletes the old function. Tests for that game stay green before the next game moves. None of these five write a new save field.

### 1. Payback label

Add `Arcade.paybackLabel(seconds)` in `shared/engine.js`, beside `fmtTime`, with the rule at `games/night-market/model.js:387-391`. Point Night Market's `paybackLine` at it and delete the local function. Run the Night Market page. Point Saltmarsh's `paybackLine` at it and delete `games/saltmarsh-shipping/model.js:594-598`. Run the Saltmarsh page. The sentences in `paybackLine` stay where they are.

### 2. Whole-coin formatting

Add `Arcade.fmtWhole(n)` in `shared/engine.js` with the rule at `games/saltmarsh-shipping/model.js:253-258`. Point Saltmarsh's `coins` at it so `coins` becomes a one-line call, and keep the name `coins` until the office reads the same. Run the Saltmarsh page. Point `Idle`'s private `plainFmtI` (`shared/idle-core.js:48-60`) at `Arcade.fmt` / `fmtWhole` when Arcade is present, and keep the fallback only for a page that forgot to load `engine.js`. Run the idle-core page. Night Market can switch coin labels from `Arcade.fmt` to `Arcade.fmtWhole` in a third step, because that changes "12.50" style under 1,000 into whole coins; do that only if the Night Market checks expect the new text. Leave Keymaster's `money` at `games/keymaster/game.js:6` on exact dollars.

### 3. Welcome-back panel

Add `shared/away-panel.js` with one function, `AwayPanel.fill(element, { title, lead, lines, button })`, using `textContent` the way Saltmarsh already does (`games/saltmarsh-shipping/game.js:1021-1043`). Then load it on the Night Market page, call it from `showAway` (`games/night-market/game.js:327-334`), and delete the `innerHTML` string. Run the Night Market page. Each game still builds its own `awayCopy`.

### 4. Bulk mode switch

Saltmarsh's `setBulk` (`games/saltmarsh-shipping/model.js:758-760`) calls it and then treats `'next'` as `1`, so an office save never gains a Next value. Point Night Market's `setBulk` at it with `'next'` kept. Run the idle-core page, then Night Market, then Saltmarsh. Leave `quote`, the payback cap and the boat goal cap in the games. Do not change the values written to `bulk`.

### 5. Milestone looks and times words

Add `Idle.lookIndex(owned)` with the thresholds at `games/night-market/model.js:136-141`, and `Idle.timesWord(multiplier)` with the words at `games/night-market/model.js:166-176`.
