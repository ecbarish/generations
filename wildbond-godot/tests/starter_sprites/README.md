# Original starter art audition

See [production report](../../../docs/art/starter-production/README.md) for approved identities, all prompts/provenance, source/renderer limits, launch/check commands and evidence. Run Play Starter Sprites.bat. This scene never loads the real player profile and never saves.

Source PNG bytes are unchanged. Frame measurement reads alpha only. The game materials provide a fixed reference pixel budget and 16-colour rendering; source files are not hand-cleaned final low-resolution atlases. Five drawn directions are mirrored for eight-way movement; four stride poses per direction, two battle poses per front/back. The settled overworld pose is not a dedicated idle animation set. New stats, saved starter selection, evolution and production export are outside this art task.
