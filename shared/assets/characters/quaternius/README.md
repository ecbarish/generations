# Paired body prototype intake

Female base and travel/ranger composites from the already downloaded Quaternius free Standard archives, licensed CC0 in the two preserved notices. Existing male counterparts stay in experiments/realmbound-3d/assets/quaternius; the registry points to both rather than duplicating them.

Reproduce with `node tools/import-character-variants.cjs <extracted archives root>` (optional sharp dependency). Textures are embedded at up to 512px using the existing trial packer logic. Source skeletons remain intact. These models are prototypes, not the Higgsfield pictures turned into geometry. Base is the Superhero build; garments contain their own body geometry. Do not combine duplicate bodies. Structural checks are recorded in intake-checks.json; animation, proportions and equipment need separate visual acceptance on both variants.
