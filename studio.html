Game master mode

When it's on, every game shows a small GM button (or press Ctrl+Shift+G) with tools: give gold and items, set levels and badges, teleport, change the time of day and weather, heal, hand out creatures, and more. Before your first change in a visit, the game backs up your save (listed below), and every change is written to the log at the bottom.

Saves and backups

Close the game's tab before restoring or importing: an open game saves every few seconds and would overwrite your change.

Save doctor

Look inside a save as readable fields, fix anything that looks wrong, and change values by hand. Nothing is written until you press Save my changes, and the old save is backed up first (it appears in the list above).

Text browser

Every line of dialogue, quest text, creature and item name and description in the games, read straight from their own files, with where each one lives: the game, the file, the line and the path inside the data. Read-only: nothing here changes a game or a save. Type a few words to search the text (or a file or path, like SPECIES or stories.json).
